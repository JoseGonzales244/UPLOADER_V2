# 🧪 Scripts de Prueba Puntual / Scratch

Esta carpeta contiene scripts de exploración e investigación puntual utilizados durante el desarrollo de integraciones con Verint, Genesys y Web Scraping.

## Contenido:
- `test_single_case.py`: Prueba de caso individual de cumplimiento.
- `test_genesys_navigation.py`: Prueba de navegación y captura de tokens CDP en Genesys.
- `test_verint_transcript_api.py`: Exploración de endpoints SOAP/REST en Verint Speech Analytics.
- `test_wrapup_fields.py`: Inspección de campos de tipificación y wrapup en Genesys.

> **Nota:** Para ejecuciones productivas y de pipelines de producción, utilizar los scripts ubicados en la raíz de `tools/` (ej: `run_sync_speech.py`, `batch_verint_extractor.py`, `run_transcript_audit.py`).
